# Style guide

**Voice:** an engineer-craftsman who loves this stuff. Curious, precise, generous with credit, never snarky about failures (autopsies are respectful and constructive). English. No hype words ("insane", "game-changer"); concrete numbers instead.

**Carousel (1080×1350, 5-8 slides)**
1. Hook slide: one big line + hero image (credited)
2. What it is (1 sentence + key spec)
3-5. What's new / how it works (our diagram or annotated crop)
6. Numbers: price, movement, size, funding
7. Our take: what we'd learn from it
8. Credit + "Follow @rival_watches for weekly independent watch radar"

Typography and colours are kept to a consistent template (dark background, one accent colour, a clean sans) so the grid reads as one brand. Template files live in `slides/_template/` when created.

**Caption template**
```
<hook, ≤125 chars>

<2-4 lines: what's new, why it matters, one number>

<our take, 1-2 lines>

<question to the audience>

📷 & design: @<brand> · Campaign: <platform> (link in their bio)
#microbrandwatch #independentwatchmaking #<specific> 
```

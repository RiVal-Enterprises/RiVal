# Design inventory

One file per idea from the drawer (copy `_TEMPLATE.md` → `NNN-short-name.md`). Scan or photograph the sketches into the shared Drive folder and link them.

## Scoring (1-5 each)

| Criterion | Question |
|---|---|
| Wow | Does it stop the scroll? Would a collector talk about it? |
| Novelty | Is it new (after a prior-art search)? |
| Feasibility | Can it run on an accessible movement within the torque budget? |
| Cost | Can we make 50-100 pcs at a price people will pay? |
| Fit | Does it use our strengths (casting, engraving, finishing)? |

# The RiVal playbook

Everything we learn from other brands' wins and failures, distilled into rules for our own launch. The weekly research job adds evidence; the monthly review promotes repeated patterns into **rules**.

- [`playbook.md`](playbook.md): the rules (what we will do / avoid), each backed by cases
- [`cases/`](cases/): one short file per analysed brand or campaign (`YYYY-brand.md`)

Case template:
```
# <Brand> · <campaign/watch> · <year>
- Platform / goal / raised / backers / price:
- Movement & what was new:
- Outcome (delivered? on time? reviews? still alive?):
- What they did right:
- What went wrong:
- Lesson for RiVal (→ playbook rule #):
- Sources:
```
